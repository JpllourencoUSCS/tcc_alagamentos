# Comparação de SDKs de Mapa

| Critério | Google Maps SDK | OpenStreetMap (OSMDroid) |
|---|---|---|
| Custo | Gratuito até 28k req/mês | Totalmente gratuito |
| Integração Jetpack Compose | Excelente (maps-compose) | Trabalhosa |
| Documentação Android | Extensa e oficial | Boa, mas menor |
| Necessidade de chave | Sim (Google Cloud) | Não |
| Qualidade do mapa | Alta | Alta |

## Decisão
**Google Maps SDK** — melhor integração com Jetpack Compose e 
documentação mais completa para Android.
